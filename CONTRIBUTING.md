# Contributing to Citizen Guardian AI

We welcome contributions to Citizen Guardian AI. Please follow these guidelines to ensure a smooth development process.

## Development Process

1.  **Check for an existing issue:** Before starting work, check the Issues tab to see if your idea or bug is already being tracked.
2.  **Create a new issue:** If no issue exists, create a new one that clearly describes the feature or bug.
3.  **Fork the repository.**
4.  **Create a feature branch:** Create a new branch from `main` for your work. Please name it descriptively (e.g., `feat/user-authentication` or `fix/profile-bug`).
5.  **Commit your changes:** Write clear and concise commit messages.
6.  **Push to your branch and open a Pull Request:** Reference the issue you are addressing in your pull request description.
7.  **Wait for a review:** A project maintainer will review your code.

## Code Style

Please adhere to the code style enforced by the linters in the project (e.g., Prettier, ESLint).

Thank you for your contribution!
